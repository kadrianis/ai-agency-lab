# AI Agency Lab

Portfolio technique d’agents IA et d’automatisations métier réutilisables.

## Périmètre

- Agents : outils, orchestration, gestion des erreurs et évaluations.
- Automatisations : traitement de données, intégrations et scénarios métier.
- Qualité : tests reproductibles, jeux de données synthétiques et limites documentées.

## État du dépôt

Le dépôt est en cours d’initialisation. Aucun agent ni scénario métier exécutable n’est encore livré.

Chaque réalisation disposera de ses sources, dépendances, instructions de lancement, tests, schéma d’architecture et résultats vérifiés. Les éventuels guides de déploiement préciseront les prérequis et les limites.
